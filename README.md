# Free Lost Wallet Recovery Kit

A calm, plain-English kit for the worst Tuesday of the month: the day your wallet goes missing.

Everything in here is free, printable, and local-first. No sign-ups, no affiliate links, no data leaves your computer. You fill the templates in yourself (pen and paper works great).

_by Asdale Dynamics, LLC — plain English, step by step, never condescending._

## What's inside

| File | What it does |
| --- | --- |
| `checklist.md` | Step-by-step what-to-do, in order, first 24 hours and beyond |
| `call-list.md` | Who to call, in what order, with blank slots for numbers/account refs |
| `replacement-tracker.md` | Track every card and ID you need to replace, and shipping status |
| `police-report-template.md` | Fill-in-the-blanks police report script for the station or online filing |
| `fraud-note-template.md` | Short dispute/fraud-note letters for banks and card issuers |
| `prevention-sheet.md` | The "never again" sheet: slim wallet, copies, and backup plan |
| `print/` | One printable HTML page (`print/wallet-recovery-print.html`) with the full kit formatted for paper |
| `STATUS.md` | What was built, how to run it, verification results, known gaps |

## How to use it

1. Open `checklist.md` and start at the top. Don't read ahead; the order matters.
2. Copy `call-list.md` and `replacement-tracker.md` into a notes app or print them from `print/wallet-recovery-print.html`.
3. If the police report or dispute letters are needed, fill in the blanks and go.
4. When the dust settles, do the `prevention-sheet.md` once. It takes about 30 minutes.

## Printing the HTML

Open `print/wallet-recovery-print.html` in any browser (double-click it), then print with Ctrl+P / Cmd+P. Page-break rules and print styles are built in. No internet needed.
